---
description: "Обновить документацию по результатам работы над тикетом"
argument-hint: "[ticket-id]"
allowed-tools: Read, Write, Glob, Grep
---

Используй subagent `writer`.

1. Установи атрибут STAGE в .active_ticket в значение DOC.
2. Прочитай артефакты по тикету `$1`:
   - `docs/prd/$1.prd.md`,
   - `docs/plan/$1.md`,
   - `docs/tasklist/$1.md`,
   - `reports/qa/$1.md` (если есть).
3. На основе этих артефактов и diff'a в коде:
   - Внеси изменения в README.md файлы для каждого изменяемого в задаче модуле проекта, чтобы содержание описание модуля соответствовало последним изменениям.
4. Покажи diff по документации пользователю.
