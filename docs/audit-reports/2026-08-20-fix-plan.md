> Примечание: в H-02 тикет SC-3 закрывает часть «фронт-раннинг» (атомарная
> инициализация через прокси). Часть «deploy-скрипт передаёт неверное число
> аргументов» вынесена в отдельную задачу деплоя вне замечаний аудита.
>
> Примечание к H-03 (SC-4): продакшн-токен — native USDC Circle на Polygon
> `0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359` (FiatTokenProxy → FiatTokenV2_2).
> По исходникам `centrehq/centre-tokens` (`FiatTokenV2.sol` + `FiatTokenV2_2.sol`
> + `EIP3009.sol`) `receiveWithAuthorization` существует в ДВУХ перегрузках:
> split `(uint8 v, bytes32 r, bytes32 s)` (унаследована из FiatTokenV2) и
> `bytes memory signature` (добавлена в FiatTokenV2_2 для EIP-1271). Интерфейс
> контракта со split-сигнатурой совместим с USDC. Семантика для мока: EIP-712 домен
> `version = "2"`, `RECEIVE_WITH_AUTHORIZATION_TYPEHASH =
> 0xd099cc98ef71107a616c4f0f941f04c322d8e254fe26b3c6668db87aae413de8`, проверка
> `to == msg.sender`, nonce по `authorizer → nonce → bool`, подпись `r||s||v`.
> TODO: подтвердить наличие обеих перегрузок по живому ABI с ноды (публичные RPC
> были недоступны из текущей сети) — проверить с домашнего компьютера.
>
> Примечание к I-03: приведение тестов и deploy-скрипта в соответствие с ABI **не
> делается** в скоупе исправлений замечаний аудита. Под это будет отдельный эпик
> (тесты + `scripts/deploy.ts`).
>
> Примечание к SC-5 (L-01/L-03/L-04): принято решение **не менять** поведение:
> - L-01 — `topUpClientBalance` доверяет админу (параметры `value`/`from` не проверяются).
> - L-03 — комиссия округляется вниз (round down) — зафиксировано.
> - L-04 — возврат средств только на `lastInboundAddress` — соответствует бизнес-модели
>   возврата на последнее платёжное средство (адрес последнего платежа).
> По M-03: верхняя граница `feePercentage` (100) оставлена как есть; добавлено событие
> `FeeConfigSet` и `setFeeConfig` переведён на `onlyOwner`.
> По I-02: `STORAGE_LOCATION` перегенерирован из `"SettelmentsControl.storage"`
> (новое значение `0xa3644cd4f32df58f1c4770a51fd2c07989147cd3f86e6250ba65ac2657ec7f00`),
> `scripts/calc.js` переведён с `web3` на `ethers`.
>
> Примечание к I-04: принято — админ прокси держится на мультисиге Gnosis Safe
> (начиная с 1-of-1, с возможностью расширения до M-of-N через `owners`/`threshold`
> внутри Safe). Код контрактов не меняется: это операционное решение на этапе деплоя —
> завести Safe и вызвать `changeProxyAdmin(safeAddress)`. Таймлок не добавляется.
